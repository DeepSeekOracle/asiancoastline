How to use the free listen player

The player at /listen.html is a full browser listening room: search the catalog, filter by album or Haven books, build a queue, shuffle, run radio, crossfade, and install it as an app. Here is the short version.

Open the player and find a track

Go to /listen.html. The player loads the public catalog and shows the full track list. Use the search box for a title, an ISRC, or a hash fragment. The sort menu orders by title, size, or ISRC presence; the filter menu narrows to playable tracks or tracks with an ISRC.

The chips under the toolbar are the fast path: Music for the main catalog, Haven books for the Eternal Haven audio, Favorites for what you have hearted, and Queue for what you have lined up. The library is large; searching is faster than scrolling.

Play, pause, and move through the catalog

Click a row to play it. The dock at the bottom holds play/pause, previous/next, shuffle, radio, repeat, volume, crossfade, and the sleep timer. On desktop, the keyboard is quicker: Space play/pause, N/P next/previous, S shuffle, R radio, F favorite, and / search.

Radio keeps playing after the current track. Shuffle changes the order. Repeat one holds a single track. Crossfade blends the end of one track into the next; the sleep timer stops playback after 15–90 minutes, which is useful for a listening session at night.

Favorites, queue, and sharing

The heart button saves a track to your local favorites. Favorites are stored in your browser, not on an account. The queue lets you line up a few tracks without losing your place. The share button copies a link to the current track or opens the share sheet on mobile.

If you clear your browser storage, favorites and queue are lost. That is the trade-off for not requiring an account. If you want a permanent list, keep a note or a playlist file outside the browser.

Install it as an app

On Chrome or Edge, use the install button in the toolbar or the browser menu’s Install / Add to Home Screen option. On iOS Safari, use Share → Add to Home Screen. The installed version opens the same player in a standalone window and keeps the basic shell cached, so it feels less like a website and more like a small app.

Mobile and data use

The player is responsive; the track list, dock, and controls stack on a phone. Streaming uses data like any browser audio: a long session can consume hundreds of megabytes. On a metered connection, lower the volume, use shorter sessions, or download the tracks you own elsewhere rather than streaming for hours.

Troubleshooting

  • A track will not start. Try another track first; if only one fails, the stream file may be missing from the public catalog. The ledger shows what is expected.
  • Playback stops when the screen locks. Mobile browsers may suspend background audio. Keep the tab active or use the installed app where the browser allows it.
  • The list is empty after a filter. Clear the search and set the filter back to All. The Haven filter only shows audio tagged as Haven books.
  • No sound. Check the volume slider in the dock, the system volume, and whether another tab is holding the audio session.

The player does not require an account and does not upload your listening history. The privacy policy covers the hosting, streaming, and advertising layers.

A five-minute listening session

If you want a useful first session, do not start with shuffle. Pick one album from the catalog, queue the first three tracks, and turn crossfade off so you hear the transitions the artist chose. Set the sleep timer to 30 minutes if you are listening at night. Use the search box to find the album by name, then let the queue run.

After three tracks, open the ledger tab and look at the hashes. The ledger is not required for listening, but it shows that the public catalog has a verifiable record. If a track fails, note the title and whether the other tracks on the same album play; that is the difference between a single missing file and a network problem.

On a phone, add the player to the home screen before you start. The installed shell opens faster and avoids the browser chrome taking up the screen. If you are on a metered connection, keep the session short and avoid leaving radio running in the background for hours.

FAQ

Do I need an account to listen?

No. The player opens without a signup. Favorites and queue are stored locally in your browser.

Can I download the tracks?

The player streams the public catalog. It is a listening room, not a download store. The terms explain the listening license.

Why does the catalog show Haven books?

The same public player carries the Eternal Haven audio alongside the music. Use the Haven chip to isolate it, or All to see everything.

Does the player work offline?

The installed app caches the shell, but the audio streams from the public catalog. Full offline listening would require downloading files you own.
